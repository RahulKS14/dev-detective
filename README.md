# Dev Detective - Prompts Documentation

This document describes the prompts and requirements used to plan and develop the Dev Detective application.

## Prompt 1: Project Development

Create a GitHub profile explorer named Dev Detective using HTML, CSS, and JavaScript. Use the GitHub REST API to retrieve public user information and display it in a clean, modern interface.

## Prompt 2: GitHub Profile Search

Implement a username search feature that retrieves a GitHub user's profile, including their avatar, name, bio, location, account creation date, followers, following, and public repository count.

## Prompt 3: Repository Display

Retrieve the user's public repositories and display the five most recently updated repositories. Each repository should include its name, description, star count, fork count, last update date, and a clickable link.

## Prompt 4: Battle Mode

Create a Battle Mode that accepts two different GitHub usernames. Fetch both profiles and their repositories, calculate the total stars, and highlight the user with the higher star count. Display a tie when both users have the same total.

## Prompt 5: Responsive Interface

Create a responsive interface that works on desktop computers, tablets, and mobile devices. Use flexible layouts, appropriate spacing, readable typography, and responsive CSS rules.

## Prompt 6: Dark and Light Themes

Implement a theme toggle that switches the interface between dark and light themes using CSS variables and JavaScript.

## Prompt 7: Error Handling

Handle invalid usernames, missing users, network failures, and GitHub API rate limits. Display appropriate status messages instead of leaving the interface blank.

## Prompt 8: Code Quality

Organize the application into separate HTML, CSS, and JavaScript files. Use reusable functions, clear variable names, safe DOM updates, and maintainable code.

## Prompt 9: Testing and Validation

Test the application with valid usernames, invalid usernames, users with no repositories, different star counts, equal star counts, and different screen sizes.

Verify that profile links and repository links open correctly.

## Expected Outcome

The completed application should provide an easy way to explore GitHub profiles, review recent repositories, compare developers, and switch between visual themes.

The application should be responsive, user-friendly, and capable of handling common API errors.
